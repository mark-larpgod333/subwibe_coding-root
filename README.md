# Subwibe Coding
Пиксельный 2D-раннер в стиле **Subway Surfers**, работающий прямо внутри встроенного **WebUI** менеджеров рут-прав (**APatch** / **KernelSU**).

## Особенности
* **Полностью автономный WebUI:** Весь движок, графика и 8-битный синтезатор звуков (Web Audio API) находятся в одном файле `webroot/index.html` без внешних картинок и аудиофайлов.
* **Выбор из 3 персонажей:** Джейк (Классика), Ниндзя (Тень) и Кибер (Неон) с сохранением прогресса и рекордов в `localStorage`.
* **Механика погони:** Полицейский со служебным псом преследует игрока на старте и при столкновении с барьерами (система второго шанса).
* **Управление:** Свайпы по экрану на смартфоне (`← / → / ↑ / ↓`) или стрелки + `Пробел` в браузере на ПК.

## Установка
1. Скачайте готовый архив `subwibe_coding.zip` из раздела **Releases**.
2. Откройте **APatch**/**KernelSU** → вкладка **Модули** (**Модули AP** для **APatch**) → **Установить из хранилища**.
3. Выберите `subwibe_coding.zip` и перезагрузите устройство.
4. Нажмите на иконку **WebUI** в карточке модуля `subwibe coding` для запуска игры.
